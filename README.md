# Product Research AI Agent 🛍️

An AI-powered product research assistant that helps users **search, analyze, compare, and recommend products** using current web information.

## Features

* 🔍 Web search using Tavily
* 🤖 AI agent using LangChain
* ⚖️ Product comparison
* 📋 Product information
* 🧠 Conversational memory
* 💡 AI-based recommendations

## Technologies

* Python
* LangChain
* LangGraph
* OpenAI
* Tavily
* GitHub

## Project Structure

## Example

```text
Compare iPhone 16 and Samsung Galaxy S25
```

The agent searches for relevant information, compares the products, and provides a recommendation.
